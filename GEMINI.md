# Reglas del Proyecto: GastroTime

- **Sincronización automática con GitHub**: Siempre que se realicen y guarden cambios en los archivos del proyecto (código, estilos, interfaz o documentación), realiza automáticamente `git add`, `git commit` con un mensaje descriptivo y `git push origin main` para mantener el repositorio remoto siempre actualizado sin necesidad de que el usuario lo pida.
